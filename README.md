# Facebook Reels Converter

## Deploy online
1. Create a GitHub repository and upload all files in this folder, including the api directory.
2. Sign in to https://vercel.com with GitHub.
3. Choose Add New > Project > Import your repository.
4. Framework Preset: Other. Root Directory: repository root. Deploy.
5. Open the URL provided by Vercel and share it.

## Limitations
- Facebook share/r links may not resolve when Facebook blocks anonymous server requests.
- The converter does not bypass privacy settings or guarantee access to a Reel.
- API only allows HTTPS Facebook hostnames to reduce SSRF risk.
